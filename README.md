# 3d_model_generator

Генератор развёртки корпуса электронного блока из листового металла. По наружным размерам и параметрам гиба программа считает развёртку, проверяет технологичность и записывает DXF для лазерной резки.

## Возможности

- расчёт развёртки по наружным размерам корпуса `L × W × H`, толщине `t`, внутреннему радиусу гиба `r` и K-фактору `k`;
- контур развёртки (крест) и линии гибов;
- два отверстия Ø3,4 в дне корпуса;
- проверки технологичности с числами: факт, норма, результат «OK/НЕТ»;
- экспорт в DXF: слой `CUT` (контур и отверстия) и слой `BEND` (линии гибов, штриховая линия);
- запуск из командной строки.

## Установка

```
git clone https://github.com/michaellm5252/3d_model_generator.git
cd 3d_model_generator
pip install -r requirements.txt
```

Нужен Python 3.9 или новее. Зависимости: `ezdxf` (запись DXF) и `pytest` (тесты).

## Использование

```
python cli.py --length 196 --width 116 --height 58.5 --t 1.5 --r 1.5 --k 0.4 --output out.dxf
```

Пример вывода:

```
Развёртка: 307.60 x 227.60 мм
  [OK ] минимальное расстояние от отверстий до линии гиба  34.95 (норма 4.50)
  [OK ] диаметр отверстия                                   3.40 (норма 1.50)
  [OK ] длина полки                                        55.50 (норма 4.50)
file saved as out.dxf
```

### Аргументы

| Аргумент   | Смысл                                   | По умолчанию |
|------------|-----------------------------------------|--------------|
| `--length` | длина корпуса (наружная), мм            | обязательный |
| `--width`  | ширина корпуса (наружная), мм           | обязательный |
| `--height` | высота корпуса (наружная), мм           | обязательный |
| `--t`      | толщина листа, мм                       | 1.5          |
| `--r`      | внутренний радиус гиба, мм              | 1.5          |
| `--k`      | K-фактор, 0 < k ≤ 0,5                   | 0.4          |
| `--angle`  | угол гиба, градусы                      | 90           |
| `--output` | путь к DXF-файлу                        | `out.dxf`    |

Справка: `python cli.py --help`.

### Коды возврата

| Код | Значение                                              |
|-----|-------------------------------------------------------|
| 0   | всё посчитано, все проверки пройдены                  |
| 1   | файл записан, но одна из проверок технологичности «НЕТ» |
| 2   | неверные параметры (например, отрицательная длина)    |

## Как считается развёртка

```
BA   = радианы(угол) · (r + k·t)          припуск на гиб
OSSB = (r + t) · tan(угол / 2)            внешний отступ (для 90° равен r + t)
BD   = 2·OSSB − BA                        вычет на гиб

длина развёртки  = L + 2H − 2·BD
ширина развёртки = W + 2H − 2·BD
```

Эталонный пример: `L=196, W=116, H=58.5, t=1.5, r=1.5, k=0.4` даёт `BA ≈ 3,2987`, `BD ≈ 2,7013` и развёртку **307,60 × 227,60 мм**. При угле 0° развёртка равна `L + 2H` и `W + 2H`, то есть 313 × 233 мм.

## Допущения

- Линии гибов проходят по середине зоны гиба.
- Углы креста вырезаны по прямой, компенсационных вырезов нет.
- Отверстия: два, Ø3,4 мм, по оси дна вдоль длины, симметрично относительно центра, шаг 120 мм (согласован с лапами кронштейна). Значения заданы в коде.
- Расстояние от отверстия до гиба мерится от линии гиба (середины зоны), от кромки отверстия.
- Длиной полки в проверке считается прямая часть `H − OSSB`.

## Проверки технологичности

| Правило                                            | Норма      |
|----------------------------------------------------|------------|
| расстояние от кромки отверстия до линии гиба       | не меньше `2t + r` |
| диаметр отверстия                                  | не меньше `t`      |
| длина полки                                        | не меньше `3t`     |

Невозможная геометрия (например, высота не больше `r + t`) не проверка, а ошибка параметров: программа завершается с кодом 2.

## Структура репозитория

```
enclosure/
  params.py        параметры корпуса и проверки их корректности
  bend.py          формулы гиба: BA, BD, размер развёртки
  flat_pattern.py  контур, линии гибов и отверстия развёртки
  checks.py        проверки технологичности
  dxf_export.py    запись DXF (слои CUT и BEND)
cli.py             командная строка
tests/             тесты pytest
docs/              скриншот
```
